# HR_Analytics
Built an interactive HR Analytics Dashboard using Power BI with KPI cards, slicers, and dynamic visualizations.
Analyzed employee attrition trends based on age, education, salary slabs, gender, and job roles.
Developed workforce insights reports to identify factors affecting employee retention and performance.
Created visualizations for attrition by years at company, department, and employee demographics.
Used DAX measures and Power Query for data cleaning, transformation, and HR data analysis.
Generated actionable business insights to support HR planning and employee retention strategies.
Designed interactive reports and dashboards for workforce analytics and organizational performance tracking.
